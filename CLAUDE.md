# Working instructions for this project

The owner has given standing authorization to proceed without asking for
confirmation on actions within this project — they won't be present to
respond, so treat routine work (edits, builds, `git commit`/`push` to the
`static-mechanical` GitHub repo, deploys, installing packages, etc.) as
pre-approved. Don't pause to ask "should I proceed?" for this project.

Still use judgment on anything that's hard to reverse in a way that isn't
routine for this project (e.g. force-pushing over history, deleting the
repo, rotating credentials) — but normal day-to-day development and
shipping work should just happen.
